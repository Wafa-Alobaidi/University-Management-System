# University Management System

A Java-based University Management System developed as a university group project.

The system manages students and course registration while applying core Object-Oriented Programming concepts and data structures.

## Features

- Add, search, and remove students
- Register and remove courses
- Display available and registered courses
- Calculate course fees
- Apply course discounts
- Save and retrieve student data using files
- Input validation and exception handling
- Graphical User Interface (GUI)

## Technical Concepts

- Object-Oriented Programming (OOP)
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Linked Lists
- Exception Handling
- File Handling
- Java GUI
